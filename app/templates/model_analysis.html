How the model works
  1. Learn normal machine operating patterns.
  2. Estimate hidden-state transition probabilities.
  3. Model sensor observations using Gaussian distributions.
  4. Calculate the likelihood of incoming observation windows.
  5. Flag windows whose scores fall below the normal-data threshold.
